# Verified schedule switching for crosstalk identification in quantum error correction

Open-source implementation of verified schedule switching: syndrome-extraction units that share gates and gate order but differ in which operations overlap are verified against a declared set of crosstalk couplings, and switching between them is used to identify concurrency-induced (ZZ) couplings from detector statistics, to monitor the observation model, and to select the unit used for protection.

## Contents

| Path | Purpose |
|---|---|
| `vss/core.py` | Schedule compilation on Stim circuits, circuit-level noise and crosstalk model (one ZZ channel per spectator pair and gate moment), fault-distance verification, exact parity model `y_u = -1/2 ln E[(-1)^{u.z}]` |
| `vss/bank.py` | Candidate units (retiming by spatial bipartitions, sham idle insertion), verified banks, design matrices `B` (nuisance) and `A` (crosstalk), nuisance-adjusted identifiability |
| `experiments/e1_bank_frontier.py` | Verified banks and identifiability versus the radius of the verification set |
| `experiments/e234_identification.py` | Model validation, finite-sample decisions, estimation and residual monitoring |
| `experiments/e5_protection.py` | Protection under a crosstalk onset with PyMatching decoding |
| `figures/` | Figure scripts and generated figures |
| `results/` | JSON outputs of every experiment |

## Codes and circuits

* Distance-5 rotated surface code, X-basis memory, 3 rounds (`surface_code:rotated_memory_x`).
* Distance-5 triangular 6.6.6 color code `[[19,1,5]]`, XYZ memory with one auxiliary qubit per face, 3 rounds (`color_code:memory_xyz`). This reference circuit has circuit-level fault distance 3.

Both are the circuits generated by Stim; schedule variants preserve gates and gate order.

## Reproduce

```bash
pip install -r requirements.txt
./run_all.sh
```

All random seeds are fixed in the scripts. Results were produced with Python 3.13.18, stim 1.16.0, pymatching 2.4.0, numpy 2.5.3, scipy 1.18.1, matplotlib 3.11.2.

## Scope

The verification criterion implemented here is preservation of the circuit-level fault distance of the reference circuit when every coupling of the declared set fires once per opportunity. Composable input/output tests for flagged protocols are not implemented. The crosstalk model is stochastic, pairwise and ZZ-only.
